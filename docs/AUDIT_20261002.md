# 数值审查与整改 — 2026-10-02

## 已修复的实现问题

1. 比较脚本原用 N=24 的表切片给 N=4 等实验，概率分母错误；正计数可能映射为负残差。当前按真实 N 生成表，保留固定训练噪声作为显式敏感度条件。
2. 原 Blackman–Harris 入口把直流计入 SNDR，且未以满量程参考归一化。新入口分别提供 bin power 与 density，以已知频率的正弦拟合计算含谐波的 SNDR。
3. 原“典型 N=22”实际从离散扫描挑选到 N=24；现独立运行 N=22，并从其自身原始数据计算 Raw 基准。
4. Monte Carlo 调用向一维 HT-LA/Adaptive 查表接口传入二维修正矩阵；现提供一维全残差表。
5. 原比较入口声明 N_MC 但未执行该重数；现明确固定种子的单次噪声实现。
